Users, File Permissions & Secrets

The service runs as a dedicated chatapp user: systemctl show chatapp -p User -p Group: User=chatapp Group=chatapp The chatapp database is used by chatapp@localhost, and it only has privileges for that database. The deployed code is owned by ubuntu, chatapp user can only read/execute it. The secrets are stored inside /etc/chatapp/chatapp.env // tarinoi lisää tähän

Nginx Configuration (/viikko5/)

/viikko5/ was added to the nginx configuration by adding include snippets/chatapp.conf; to the existing server{} block. This means all the nginx changes related to chatapp are done to chatapp.conf rather than changing the previous parts

Model Choice, Memory & Disk Usage

Tried some models, qwen2.5:3b seems to be a bit smarter than the original while still being fast enough. qwen2.5:3b takes about 2.2gb ram of the server's 7.6gb total ram. Disk usage: this qwen model takes only 1.9gb out of 76gb total. df -h / Filesystem Size Used Avail Use% Mounted on /dev/vda1 77G 8.3G 69G 11% /

Database Replication to Server B (Week 4)

The chat database is replicated to server B. There are no filters in place that would make the replication exclusive to the week 4 database. i confirmed this by checking SHOW REPLICA STATUS\G Replicate_Do_DB: Replicate_Ignore_DB:
